# Online Retail 电商用户复购分析与 RFM 客户分层

## 1. 项目简介

本项目基于 UCI Online Retail 历史交易数据，使用 Python 和 Excel 对电商客户的复购行为、消费特征及客户价值进行分析，并通过 RFM 模型识别不同客户群体，为客户维护、复购促进和流失风险管理提供参考。

## 2. 项目目标

- 完成原始交易数据的质量检查与清洗
- 分析客户复购情况和订单行为
- 基于 Recency、Frequency、Monetary 建立客户评分体系
- 对客户进行分层，比较各类客户的规模与销售额贡献
- 通过图表和 Excel 报告呈现分析结果及业务建议

## 3. 数据来源

数据集：UCI Online Retail

来源链接：https://archive.ics.uci.edu/dataset/352/online+retail

原始数据约 541,909 条交易记录，包含发票编号、商品编码、商品描述、购买数量、交易时间、单价、客户编号和国家等字段。

## 5. 分析流程

1. 数据读取与结构检查
2. 缺失值、取消订单、异常数量及价格检查
3. 数据清洗与清洗结果验证
4. 客户复购行为分析
5. RFM 指标计算与五分位数评分
6. 客户分层与分群统计
7. 客户分层可视化
8. Excel 分析报告生成

## 6. 核心分析结果

- 原始记录数：541,909
- 清洗后交易记录数：397,884
- 清洗后客户数：4,338
- 清洗后订单数：18,532
- 清洗后累计销售额：8,911,407.90
- 复购客户数：2,845
- 复购客户占比：65.58%

以上金额为数据集中的历史交易金额，不能直接代表企业利润。

## 7. 客户分层发现

基于当前 RFM 评分和业务规则：

- Champions：946 人，占 21.81%，累计消费额约 575.95 万
- Hibernating：992 人，占 22.87%，是人数最多的客户群体
- High Value At Risk：346 人，占 7.98%，具有较高的历史消费金额，但近期购买活跃度较低

Champions 客户贡献了约 64.63% 的清洗后累计销售额，说明该分层具有较高的销售额集中度。

## 8. 业务建议

- 维护高价值活跃客户，探索会员权益和个性化推荐
- 对沉睡客户开展分层召回测试
- 对高价值流失风险客户尝试定向挽回
- 关注一次购买客户的后续转化，分析其复购障碍

上述建议属于基于历史数据提出的运营方向，实际效果仍需通过后续实验验证。

## 10. 方法说明与局限

RFM 模型使用最近一次购买时间、不同订单数和累计消费金额描述客户行为。评分采用五分位数方法，客户分层采用项目中定义的业务规则。

数据来自 2010—2011 年的历史交易记录，结论主要用于展示分析方法。项目未进行随机对照营销实验，因此不能据此认定某项运营策略必然提升复购或销售额。
